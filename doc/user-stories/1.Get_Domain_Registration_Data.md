### Description

As an SEO auditor,
I want to get the domain registration data for a given domain name
So that I can verify the domain name is registered.

### Acceptance Criteria

1. The system will
   get the domain registration data
   for a given domain name.
1. If the domain name is not registered,
   the system will return an error message.
1. If an error occurs while retrieving the data,
   the system will return an error message.
1. Evals can use andexor.net as a good example
   of a domain name that is registered.
1. Evals can use andexor-nxdomain.net
   as a bad example since it does not exist.
1. Evals should also use other existing domains
   with a TLD that is not .com, .net, or .org.

### Technical Details

1. The is the meta use case for the system.
1. This will be implemented
   as an agent that will call the
   web services that implement
   the other use cases.
1. It will take a domain name from a prompt.
1. It will first call the
   AGS RDAP Bootstrap Service
   to get a link to the designated
   RDAP Authoritative server
   for the given domain name.
1. Then it will call the
   AGS RDAP Authoritative Service
   and give it the URL to the domain's
   RDAP Authoritative server.
1. Finally, it will return a curated subset
   of the response data to the caller.
1. The agent will be written in Python.
1. It will use the Anthropic API.
1. The agent will emit telemetry data
   as logs, metrics, and traces.
1. All requests, responses,
   observations, and decisions
   will be saved in a database
   for analysis and reporting.
